### AirAlertPro — система автоматичного оповіщення про повітряну тривогу

**AirAlertPro** — програмно-апаратна система автоматичного оповіщення про повітряну тривогу, розроблена на базі мікроконтролера **ESP32 (Wemos D1 Mini ESP32)**.

Система отримує інформацію через **Ukraine Alarm API**, розрізняє жовтий і червоний рівні загрози та автоматично керує до 8 програмованими виходами за індивідуальними сценаріями. Підтримує голосові повідомлення через **DFPlayer Mini**, хвилину мовчання за розкладом, Telegram-сповіщення, інтеграцію з **Home Assistant через MQTT**, журнал на 1000 подій та оновлення OTA.

**Технології:** C++ / Arduino Framework, PlatformIO, ESP32, HTML/CSS/JavaScript, LittleFS, REST API, MQTT.

Передбачено двомовний вебінтерфейс (UA/EN) для налаштування, керування та моніторингу.
